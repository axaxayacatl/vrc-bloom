# VRChat World Note

A lightweight Python terminal tool for organizing VRChat worlds, avatar ideas, creator names, instance details, and revisit notes. Designed to run locally on Windows without additional dependencies.

## Features

- **Add notes** — Save worlds, avatars, creators, instances, and other ideas.
- **Browse notes** — View all saved entries with their categories and timestamps.
- **Search** — Find notes by title, details, or category.
- **Delete entries** — Remove notes you no longer need.
- **Export** — Generate a plain-text document of your saved notes.
- **Local storage** — Keep your data in a JSON file on your own computer.

## Requirements

- Python 3.9 or newer recommended.
- Windows, macOS, or Linux with Python installed.
- No third-party Python packages required.
- No VRChat API key or Unity installation required.

## Installation

1. Download or clone this project.
2. Extract the project folder if downloaded as a ZIP archive.
3. Open a terminal in the project directory.

## Usage

Run the application from your terminal:

```bash
python vrchat_world_note.py
```

On Windows, you can also use:

```powershell
py vrchat_world_note.py
```

The interactive menu provides these options:

| Option | Action |
|---|---|
| `1` | Add a note |
| `2` | View all notes |
| `3` | Search notes |
| `4` | Delete a note |
| `5` | Export notes as text |
| `0` | Exit |

When adding a note, choose a category such as `World`, `Avatar`, `Creator`, `Instance`, `Idea`, or `Other`. Enter a title and add relevant details, such as a VRChat world link, creator information, or a reminder to revisit a location.

## Data Storage

The application creates its data files in the same directory as the Python script.

- `vrchat_world_notes.json` — Stores saved notes in JSON format.
- `vrchat_world_notes.txt` — Contains the plain-text export generated by the export option.

Your notes persist between sessions. Back up the JSON file to preserve your saved entries when moving the application to another computer.

## Project Structure

```text
vrchat_world_note/
├── README.md

```

The JSON database and text export are generated when you use the application.

## Scope and Limitations

VRChat World Note is an independent, local note-taking utility. It does not connect to your VRChat account, automatically detect visited worlds, retrieve avatar information, interact with live instances, or modify the VRChat client.

All information is entered manually and stored locally.
