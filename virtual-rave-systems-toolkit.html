README

V 1.0.0

Virtual Rave Systems Toolkit

A lightweight starter kit for contributing code to virtual rave culture without needing to perform. Includes an event board, browser audio visualizer, and a small lineup archive.

Run locally

  1. Extract the ZIP file.
  2. Open index.html in a modern browser.
  3. Add events and track metadata. Data is saved in this browser's local storage.
  4. Use the export buttons to download JSON snapshots.

Current capabilities

  • Responsive interface; keyboard-accessible forms and tabs.
  • Local event and track metadata storage.
  • JSON export for backup or future integration.
  • Audio file selection and canvas visualizer, processed client-side.

Limitations

  • This is a local prototype, not a hosted submission platform.
  • Local storage is tied to this browser and device; export backups.
  • Event links and submissions are not automatically published to communities.
  • No VRChat SDK integration or real-time multi-user synchronization is included.

Built as an open, editable prototype. Before deploying publicly, add moderation, privacy disclosures, event verification, and a hosted data layer.
